# STAGE 1C — каталог первых 100 головоломок

База — `32b31d91b20a33ef1fb6198f0c97619fe8e9538d`. В каталоге один исходный Tutorial и 99 сгенерированных полей. Все 100 решены через игровую модель. [Статистика каждого уровня и seed](stage_1c_metrics.csv) · [13 кадров игры](screenshots/stage_1c/).

## Получившаяся прогрессия

В каждой ячейке приведены минимум / медиана / максимум. Занятость — доля клеток поля, изгибы — доля стрелок хотя бы с одним поворотом, свободные — доля допустимых первых ходов. Цепочка измеряется в стрелках.

| Группа | Полей | Занятость, % | Стрелок | Изогнутых, % | Свободных, % | Цепочка |
|---|---:|---|---|---|---|---|
| Tutorial, 10×14 | 1 | 22,14 | 8 | 37,50 | 50 | 3 |
| Easy, 8×12 | 19 | 48,96 / 63,54 / 64,58 | 8 / 10 / 13 | 76,92 / 90 / 100 | 50 / 66,67 / 70 | 2 / 3 / 4 |
| Normal, 10×14 | 40 | 65 / 74,29 / 75 | 14 / 17 / 20 | 60 / 87,87 / 100 | 25 / 43,75 / 50 | 3 / 4 / 7 |
| Hard, 12×16 | 40 | 68,23 / 77,60 / 84,90 | 22 / 26 / 32 | 65,62 / 80,32 / 96,15 | 22,58 / 33,33 / 34,78 | 5 / 5 / 8 |

Внутри группы поля отсортированы по среднему пяти величин с одинаковым весом 0,2: занятость, число стрелок / 32, доля заблокированных, длина цепочки / 16 и число рёбер / (3 × число стрелок). При совпадении оценки первым идёт меньший seed. Медианы оценки — 0,33, 0,48 и 0,61 для Easy, Normal и Hard. Это оценка по структуре поля. Для оценки воспринимаемой сложности потребуются игровые сессии с людьми.

## Построение и проверка

[Генератор](../game/level_generator.gd) использует локальный RandomNumberGenerator. Он выбирает голову и направление со свободным лучом, затем прокладывает тело обратно по свободным ортогональным соседям. Тело исключает повторные клетки и собственный выходной луч. Каждая новая стрелка может выйти в момент вставки. При обратном порядке удаления после каждого хода восстанавливается предыдущее состояние поля. Это даёт конструктивное доказательство решаемости.

[Solver](../game/level_solver.gd) валидирует геометрию и строит собственный индекс клеток. Для каждого луча он учитывает каждый уникальный блокирующий ID. Послойное удаление вершин с нулевой входной степенью даёт допустимый порядок и длину максимальной цепочки. Если остались вершины, Solver возвращает deadlock и их ID. Проверены полная очистка по решению Solver, обратное свидетельство для 99 полей и три дополнительных порядка на каждом из 100 полей.

[Метрики](../game/level_metrics.gd) учитывают длины, направления, повороты, граф зависимостей и число волн. Forced и choice в CSV — число состояний с одним или несколькими допустимыми ходами на стабильном маршруте Solver, без терминального пустого поля. Направления в CSV идут вправо, вниз, влево, вверх. Для проверки уникальности выбирается каноническая запись из восьми преобразований прямоугольника, включая отражения и повороты с обменом сторон. ID и порядок записи стрелок исключены, порядок клеток внутри стрелки сохранён.

[Офлайн-команда](../tools/generate_levels.gd) ограничена 2 800 кандидатами на поле и 5 000 seed на группу. В итоговую выборку прошли 19 из 23, 40 из 105 и 40 из 877 рассмотренных seed соответственно. Seed начинаются с 100000, 200000 и 300000. Только после проверки полного сериализованного каталога временный файл заменяет рабочий. Размер [JSON](../levels/data/catalog.json) — 180 090 байт. Повторная генерация дала тот же SHA-256: `5401de5a357fba34ca8e0c2c03c78a1431dcc46ecf0929ab827416f4255d14ff`. Два замера полного построения с проверками — 2,419 и 2,195 с.

[Загрузчик](../levels/level_catalog.gd) читает версионированный JSON из res:// и проверяет ID, структуру координат, границы, геометрию, записанные решения и метрики. Модель получает собственную копию. [Игровая сцена](../scenes/game.tscn) использует один контроллер для всех полей. Следующий ID открывается после выхода последнего хвоста; на сотом поле остаётся перезапуск. Для будущего экспорта с фильтрацией ресурсов включить `levels/data/*.json` в фильтр нересурсных файлов.

## Воспроизведение и результаты

Windows, Godot 4.3.stable.official.77dcf97d8, Compatibility. Графический прогон использовал OpenGL на GeForce RTX 3050 Laptop GPU. В таблице godot означает исполняемый файл Godot 4.3; запуск из корня репозитория.

| Команда | Фактический результат | Код |
|---|---|---:|
| `godot --headless --path . --script res://tools/generate_levels.gd` | 100 записей, воспроизводимый checksum | 0 |
| `godot --headless --path . --script res://tests/stage_1a.gd` | 34 прошли, 0 ошибок | 0 |
| `godot --headless --path . --script res://tests/stage_1b.gd` | 81 прошла, 0 ошибок | 0 |
| `godot --headless --path . --script res://tests/stage_1c.gd` | 1 418 прошли, 0 ошибок | 0 |
| `python tools/catalog_statistics.py` | Независимый пересчёт метрик всех 100 записей и экспорт CSV | 0 |
| `godot --headless --path . --quit-after 10` | Запуск главной сцены | 0 |
| `godot --path . --fixed-fps 60 --script res://tests/capture_stage_1c.gd` | 13 PNG из viewport 405×720 | 0 |

Итоговый замер Solver для 100 полей, включая проверку геометрии: медиана 255 мкс, максимум 669 мкс. На 100 дополнительных seed, отсутствующих в каталоге, фильтр принял 45 полей. Easy — 24 из 34, Normal — 18 из 33, Hard — 3 из 33. Остальные 55 вышли за диапазоны метрик. Эти случаи завершились диагностикой отказа. Ошибка компиляции при первичной разработке расчёта сложности исправлена явным типом float. В итоговом тесте два ожидаемых предупреждения о выходе ID за границы соответствуют отрицательным тестам контроллера.

Оба набора регрессий сохранены без правок. Новый набор включает циклы, частичный тупик, несколько блокировщиков, повреждённые пути, независимость от состояния глобального RNG, копирование данных, смену уровня во время анимации, устаревший callback, переходы 1→2, 20→21 и 60→61, финал 100 и попадание рядом с изгибом на плотном поле через viewport при 360×640, 405×720 и 412×915.

## Визуальная и ручная приёмка

В [каталоге кадров](screenshots/stage_1c/) сохранены стартовые поля 1, 2, 10, 20, 21, 40, 60, 61, 80 и 100. Отдельно сняты [частично пройденный Hard](screenshots/stage_1c/hard-partial.png), [победа с NEXT LEVEL](screenshots/stage_1c/next-level.png) и [финал сотого уровня](screenshots/stage_1c/all-complete.png).

Для ручной проверки пройти Tutorial, дождаться выхода последней стрелки, открыть NEXT LEVEL и после нескольких ходов нажать RESTART. Должно восстановиться то же поле Level 2. На физическом Android остаётся оценить комфорт выбора стрелок на плотной сетке и воспринимаемую сложность. Автотесты использовали программные события, APK не собирался.
